# ❌⭕ XO Minimax

A Tic-Tac-Toe game built with Python using the **Minimax Algorithm**.

## 🧠 About The Project

This project is a simple Tic-Tac-Toe game where the player competes against an AI opponent.

The AI uses the **Minimax Algorithm** to analyze possible moves and choose the best move.

## 🚀 Features

- ❌ Human Player
- ⭕ AI Opponent
- 🧠 Minimax Algorithm
- 🎮 Interactive Tic-Tac-Toe Game
- 🏆 Win / Lose / Draw Detection

## 🛠️ Technologies

- Python
- Minimax Algorithm
